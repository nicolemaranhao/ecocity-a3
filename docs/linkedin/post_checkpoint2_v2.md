O banco de dados do EcoCity saiu do papel! 🌆

Água, energia, lixo e transporte: os dados das cidades existem, mas ficam espalhados em sites e formatos diferentes. O EcoCity junta tudo, mês a mês, num só banco de dados e dá uma nota de 0 a 100 para cada uma de 8 cidades de São Paulo.

Neste 2º checkpoint da A3 de Banco de Dados, nós:
✅ Priorizamos os requisitos do sistema
✅ Desenhamos o DER preliminar no draw.io
✅ Levantamos dados reais de fontes oficiais (ANEEL, EPE, SNIS, SPTrans, SEEG e IBGE)
✅ Criamos o banco no MySQL: 36 tabelas e 1.536 medições
✅ Colocamos a API no ar, com cadastro por perfil e login em 2 etapas

Nossos desafios:
• Muitas fontes só publicam dados por ano, e nós queríamos mês a mês. Por isso, cada número no banco mostra se é oficial, calculado ou estimado.
• Garantir que só pessoas autorizadas publiquem análises e definam metas. Quem cuida disso é o próprio banco: no teste, ele bloqueou a criação de um administrador "intruso".

Ferramentas: MySQL, Oracle Cloud, Node.js + Express, Python e draw.io

Próximos passos: DER final, modelo lógico, normalização e as telas do sistema.
