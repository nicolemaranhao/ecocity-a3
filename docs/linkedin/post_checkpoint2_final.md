🏙️ Concluímos o 2º checkpoint do nosso projeto, e o banco de dados já saiu do papel!

Seguimos com o EcoCity, desenvolvido em dupla com a minha colega @Gabriela Sant'Ana Merces, para a disciplina de Banco de Dados.

◇ O que já foi feito: priorizamos os requisitos, reunimos dados reais, mês a mês, de 8 cidades de São Paulo, fizemos o DER e criamos o banco no MySQL, com o back-end já funcionando (veja na 2ª imagem como o sistema funciona!).

◇ Principal desafio: muitas fontes só publicam dados por ano. Por isso, cada número no banco mostra se é oficial ou estimado.

◇ Ferramentas: MySQL, Oracle Cloud, Node.js + Express, Python e draw.io.

◇ Próximos passos: modelo lógico, normalização e as telas do sistema.
