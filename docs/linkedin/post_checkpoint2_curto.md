Mais uma etapa concluída! 🌆

No 2º checkpoint da A3 de Banco de Dados, o EcoCity saiu do papel: fizemos o DER, criamos o banco no MySQL e colocamos a API no ar. O projeto junta, mês a mês, os dados de água, energia, lixo e transporte de 8 cidades de São Paulo.

Nosso maior desafio: muitas fontes só publicam dados por ano. Por isso, cada número no banco mostra se é oficial ou estimado.

Próximo passo: DER final, normalização e as telas do sistema.
