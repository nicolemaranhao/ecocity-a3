🏙️ Concluímos a etapa de planejamento do nosso projeto, e o banco de dados já saiu do papel!

Seguimos com o EcoCity, desenvolvido em dupla com a minha colega @Gabriela Sant'Ana Merces, para a disciplina de Banco de Dados.

◇ O que já foi feito: priorizamos os requisitos, desenhamos o DER preliminar, reunimos dados reais, mês a mês, de 8 cidades de São Paulo e criamos o banco no MySQL, com a API já no ar (veja as imagens!).

◇ Principal desafio: muitas fontes só publicam dados por ano. Por isso, cada número no banco mostra se é oficial ou estimado.

◇ Ferramentas: MySQL, Oracle Cloud, Node.js e draw.io.

◇ Próximos passos: DER final, normalização e as telas do sistema.
