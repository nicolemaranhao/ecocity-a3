Concluímos a etapa de planejamento do EcoCity e o banco de dados já saiu do papel! 🌆

Água, energia, lixo e transporte: os dados das cidades ficam espalhados em sistemas que não conversam entre si. O EcoCity junta tudo isso, mês a mês, em um banco de dados com indicadores de sustentabilidade para 8 cidades de São Paulo.

O que já fizemos:
• Priorizamos os requisitos do sistema
• Desenhamos o DER preliminar (veja as imagens!)
• Levantamos dados reais de fontes oficiais (ANEEL, SPTrans, IBGE, EPE, SNIS e SEEG)
• Criamos o banco no MySQL e a API, com cadastro por perfil e login em duas etapas

Principais desafios:
• Muitas fontes só publicam dados por ano, e nós queríamos mês a mês. A solução foi marcar cada número como oficial, calculado ou estimado.
• Garantir que só pessoas confiáveis publiquem análises e definam metas.

Ferramentas: MySQL, Oracle Cloud, Node.js e draw.io

Próximos passos:
• DER final, modelo lógico e normalização
• Telas do sistema e publicação na Oracle Cloud
