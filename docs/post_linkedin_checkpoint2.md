🌆 **EcoCity — 2º checkpoint do nosso projeto de Banco de Dados**

Água, energia, resíduos e mobilidade: quatro serviços públicos, quatro sistemas diferentes e, quase sempre, dados que não conversam entre si. Nosso projeto da A3 quer resolver isso com um **Data Warehouse que integra os dados da cidade** e gera indicadores de sustentabilidade para gestores e cidadãos.

Nesta etapa nós:
✅ Priorizamos 12 requisitos funcionais e 11 não funcionais
✅ Construímos o DER preliminar em 3ª Forma Normal + um modelo estrela para o DW
✅ Definimos o MySQL 8 na Oracle Cloud (HeatWave) como SGBD
✅ Criamos o Índice EcoCity de Sustentabilidade (0 a 100) com base na ISO 37120 e nos ODS
✅ Já temos scripts SQL com triggers, procedures transacionais, views, papéis de segurança e uma primeira versão do painel

Próximo passo: finalizar o modelo lógico e publicar o banco na OCI. 🚀
